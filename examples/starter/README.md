# Bruin Starter

A simple starter template demonstrating Bruin state management.

## Set up locally

```bash
# Clone the Bruin repository
git clone https://github.com/low-orbit-io/bruin

# Install project dependencies & build the library
cd bruin && pnpm install

# Move to the examples folder & install dependencies
cd examples/starter && pnpm install

# Start the dev server
pnpm dev
```

## About Bruin

Bruin is a modern state management library that extends Zustand with powerful features like built-in history tracking, transactions, and enhanced middleware.
